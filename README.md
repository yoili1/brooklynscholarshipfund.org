# brooklynscholarshipfund.org

Website for Brooklyn Scholarship Fund Inc., served by GitHub Pages at https://brooklynscholarshipfund.org.

- `index.html` is the whole page (HTML and CSS, no build step).
- `CNAME` holds the custom domain.
- `fonts/` holds the self-hosted fonts (Bodoni Moda, Libre Franklin, Caveat), each under the SIL Open Font License.
